# 验收场景

这些是手工验收场景，不声称都完成了真实出图测试。结构检查和辅助工具测试不保证生成模型每次输出完全正确。

| 请求 | 预期行为 |
|---|---|
| 1880×960港口地图 | 目标47:24，七类信息和当地建筑拼贴，另查实际文件比例 |
| 竖向内陆地图 | 保持比例，重排模块，不凭空添加海岸，不硬塞横版 |
| 无地名截图 | 询问地点，同时准备通用风格，不猜地标 |
| 只有年代样本、没有层数 | 保留两专题，样本和未知明确，不随机涂整片楼层 |
| 只要通用提示词 | 不调用出图，不依赖另一张风格图或对话历史 |
| 生成额度不足 | 说明未生成，保留资料与提示词，不将旧图当新图 |
| 拼贴和地图编号错位 | 修正编号及图注位置 |
| 精确测绘要求 | 需要GIS数据，不以生成式图像宣称测绘成果 |

尺寸脚本检查：同一比例不同尺寸应返回0，近似但不严格相同返回1，读取失败返回2；EXIF旋转按显示方向判断。

发布前检查元数据、相对引用、模板残留与个人绝对路径。不得混入用户图片或第三方素材。
