# 单张卫星图独立提示词

仅要通用提示词时直接交付下文。真实出图前由代理完成资料检索，并将已核实事实附加到末尾；不要指望只有图像生成能力的工具自行研究。

---

将上传的卫星地图转换为专业建筑学／城市设计作品集中的综合mapping分析展板。结合地图所在地的真实地理、建筑与历史资料，完成地图转绘、多维专题分析、当地建筑影像拼贴和简洁文字说明。信息充分且有依据，视觉统一且有层次。

画幅与地图：读取原始像素宽高，成图严格保持相同宽高比，可等比例提高分辨率。保留方向、岸线、水系、道路骨架、街区形态和地标相对位置，不拉伸或改造地理。去除搜索框、按钮等界面元素，保留来源署名至页脚。主地图可等比例缩放、移动，不能以改变地理结构适应排版。

信息体系：先确认地点并检索可靠资料。必须涵盖多级区位、主地图与研究范围、建筑性质、建筑年代、建筑层数、地标与地方建筑特色、道路交通。区位按国家—省州—城市—研究区域选择层级，局部放大图与主图对应，未给项目红线时仅标观察范围。按地方特征补充0—2项历史演变、滨水、公共空间、绿地或保护主题。每个专题有小图、标题、图例／关键数值和一句解释。用途、年代、层数使用同范围、同朝向、同编号底图，便于比较。宏观地图中的建筑属性放在有数据的局部窗口，不假造逐栋调查。正文用短句和关键结论，避免百科长文。

建筑拼贴：在左下角为主、向底部延伸的位置，使用3—5组真实当地地标、典型建筑或街区的照片与历史影像。沿屋顶、钟楼、立面轮廓抠图，将街景、建筑全貌与细节结合，以高低错落、尺度变化和适度叠压形成连续建筑景观。每组配名称、已核实的年代／用途／层数及1—2句建筑特征和地方意义说明，用编号、酒红点和细引线对应地图位置。不要用地图裁切、航拍纹理、泛化天际线或等大卡片替代建筑拼贴。

色彩与影调：采用暖白#F2EFE9、烟熏灰棕#80655C、浅灰棕#AB958B、炭黑#262626、暖灰#A6A09A与少量暗酒红#68272D。整体低饱和、偏暖，具有轻微纸面印刷质感。暖白用于水体和留白，灰棕在主地图形成连续城市色块，炭黑构成重点图底和照片暗部，酒红只突出研究框、地标、编号、引线及必要分类。避免橙棕、金棕、泛黄牛皮纸、鲜红和彩虹图例。卫星图绿色植被、蓝绿色水面和彩色屋顶统一抽象至此色板。道路为精细白线及浅灰线，重点区域可切炭黑图底，外围轻化。专题同类别同色，结合明度和纹理保证可辨。照片统一中性或微暖黑白，暗部扎实、亮部干净，保留砖石和窗洞纹理，形成底部视觉重量，不套浓褐滤镜或淡化为线稿。

自适应排版：先分析地图轮廓、水系、密度、重点区域与自然留白。主地图承担空间叙事，专题围绕主图与边缘组织，拼贴形成下方基座。混用矩形、圆形和局部叠图，不固定左右分栏、圆图数量或卡片网格。水面中的专题窗口边界明确，不能像真实岛屿。信息多时先精简重复文字、合并图例和调整模块，不能无限缩小字体或省略核心专题。不得为了放模块而移动岸线或压缩街区。

图面细节：清晰无衬线文字、适度标题、精细竖线与引线、少量圆点。纸张颗粒轻微，不影响线条。添加城市名称、简短概述、图例、正确指北针、数据和影像来源；仅在能校准时添加数值比例尺。避免污渍烧边、3D地图、浮雕、强渐变和过量箭头。

真实性：用途、年代、层数、历史和交通信息必须有来源。资料不足时保留专题，仅表达已核实样本，其余标未知，不编造整片分类。历史影像不能误标现代实拍，生成重绘注明性质。概念展板标注空间分析示意，非测绘成果。

验收：检查七类信息、图文编号、图例和着色、地理关系、文字可读性及实际输出像素比例。缩小观看是灰棕主地图、暖白留白、黑白建筑拼贴与少量酒红；放大观看每个专题都有具体可信内容。
