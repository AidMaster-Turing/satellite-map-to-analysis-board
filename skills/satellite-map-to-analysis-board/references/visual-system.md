# 视觉系统与自适应排版

## 色板

| 角色 | 色值 | 用法 |
|---|---|---|
| 暖白 | #F2EFE9 | 纸底、水体、留白，避免纯白和泛黄牛皮纸 |
| 烟熏灰棕 | #80655C | 主图城市连续色块，略偏红且有灰感 |
| 浅灰棕 | #AB958B | 外围与次级肌理 |
| 炭黑 | #262626 | 重点图底、文字、照片暗部 |
| 暖灰 | #A6A09A | 次级底图、未知建筑与细线 |
| 暗酒红 | #68272D | 研究框、地标、编号和少量分类 |

暖白约45%、灰棕约30%、黑灰约21%、酒红约4%为视觉参考，不是逐像素配额。水域多的地图允许更多留白，不为比例改地形。

消除卫星图的绿色植被、蓝绿色水面和彩色屋顶残留。灰棕不能漂移成橙棕、金棕、土黄；酒红不能成为鲜红或玫红。专题同类别同色，辅以纹理、线型与明度保证可辨，不用彩虹图例。

## 地图与照片

主图是灰棕陆地、暖白水体、细白线／浅灰路网。重点区可切为炭黑图底，外围较轻。线网必须依附原图，不能用随机装饰线代替道路。有真实GIS图层时优先使用。

建筑影像统一中性或微暖黑白，暗部扎实、亮部干净，砖石与窗洞可辨。禁止浓褐滤镜或浅灰线稿替代。纸纤维与颗粒轻微，不做污渍、烧边、浮雕、发光、3D或油画。

字体清晰，标题适度；精致来自对齐和层级，不来自小到不可读的字号。

## 建筑拼贴

选择3—5组有来源的当地影像，不足时宁少勿造。可组合地标、日常街区、工业遗存，不要求每座城市都出现教堂、钟楼或烟囱。

形成连续屋顶轮廓：高建筑作锚点，横向街景或建筑群铺底，局部细节穿插。允许尺度变化与叠压，不合并成不存在的建筑。每组名称、编号、关键属性和1—2句解释在邻近留白中，用短引线指向自己的建筑。

不要等大照片卡片、无说明剪影、地图裁切或航拍纹理。档案图、照片与生成重绘应保持性质可辨，图注年份不可误当拍摄年。

## 按地图选择布局

| 输入 | 构图判断 |
|---|---|
| 海湾／港口 | 保留岸线和港汊；水面中的专题窗口有清晰边界，不像新增岛 |
| 沿河／河谷 | 顺着河流组织主图，专题在两侧留白中分布 |
| 内陆网格城区 | 主图场与局部窗口配合，不硬加海岸和滨水分析 |
| 竖向截图 | 主图纵向组织，专题分层穿插，拼贴保持视觉重量 |
| 密集且少留白 | 等比缩小主图腾出边缘，精简重复说明，不裁关键地理范围 |

主图约45%—60%、专题约20%—30%、拼贴约25%—30%是允许叠合的视觉权重，不是固定面积分割。实际按画幅和内容调整，不锁定75/25分栏或四个圆图。

阅读顺序：区位概述 → 主地图 → 属性比较 → 建筑与地方意义。拥挤时删重复文字、共用图例、移动模块，再减少次要补充主题，保留七类核心信息。

缩小观看应清楚呈现灰棕地图、暖白留白、黑白建筑基座、少量酒红；放大观看应有具体可信的信息。两者同时成立。
